# 전술판 프로토타입 (2단계)

카메라로 찍은 경기 화면의 선수 위치를 **위에서 내려다본 경기장 좌표(미터)** 로
바꾼다. 웹사이트에 아직 연결하지 않은 실험용 코드다.

## 무엇을 하고, 무엇을 하지 않는가

| 한다 | 하지 않는다 |
|---|---|
| 화면 좌표 → 경기장 좌표 변환 | 선수 자동 검출 |
| 궤적을 전술판 그림으로 | 패스·슛 같은 동작 인식 |
| 보정 오차가 결과에 미치는 영향 측정 | 실시간 처리 |

쓰는 기술은 **호모그래피 하나**다. 경기장은 평면이므로 화면에서 네 모서리만
찍어 주면 나머지 점은 모두 계산으로 변환된다. 학습도, 학습 데이터도 필요 없다.

선수를 자동으로 찾는 단계(검출·추적)는 여기 없다. 그 부분은 YOLO 같은 별도
모델이 필요하며, 이 프로토타입은 **검출이 이미 끝났다고 가정**하고 그 뒤를 맡는다.

## 실행

```bash
python -m venv .venv && source .venv/bin/activate
pip install opencv-python-headless numpy

python make_sample_clip.py        # 가짜 경기 영상 + 정답 좌표 생성
python tactical_board.py          # 화면 좌표 → 경기장 좌표 변환
python check_accuracy.py          # 변환이 맞는지 검증
python check_calibration_error.py # 클릭 오차가 얼마나 번지는지 측정
```

결과는 `out/` 에 쌓인다(git 에는 올리지 않는다).

| 파일 | 내용 |
|---|---|
| `sample_match.mp4` | 카메라 시점 가짜 경기 영상 |
| `overlay.png` | 보정점이 모서리에 맞게 찍혔는지 확인용 |
| `top_down.png` | 전술판 — 선수 궤적 |
| `tactical.json` | 프레임별 경기장 좌표(미터) |

## 검증 결과

**좌표 변환 자체는 정확하다.** 모서리를 정확히 알 때 750개 지점의 평균 오차는
0.4 mm 로, 부동소수점 반올림 수준이다.

**실제 정확도는 모서리를 얼마나 잘 찍느냐로 결정된다.** 네 모서리를 일부러
흔들어 측정한 결과:

| 클릭 오차 | 평균 위치 오차 | 최악 |
|---|---|---|
| 2 px | 0.28 m | 0.94 m |
| 5 px | 0.80 m | 2.27 m |
| 10 px | 1.55 m | 5.70 m |
| 20 px | 2.33 m | 8.50 m |

1280×720 화면에서 손으로 클릭하면 보통 2~5 px 안에 들어오므로, **위치 오차는
1 m 안팎**이다. 경기장 길이가 105 m 이므로 구역 판단에는 충분하다.

다만 이 수치는 **검출이 완벽하다고 가정한 값**이다. 실제 경기에서는 선수를
찾는 단계의 오차가 이보다 훨씬 크다. 멀리서 찍어 선수가 작게 나오거나 서로
겹치면 몇 미터씩 틀리고, 아예 놓치기도 한다.

## 운영에 넣는다면

```
경기 영상 → [이 스크립트, 학교 PC 에서 오프라인 실행] → tactical.json → 웹사이트가 렌더링
```

웹사이트(Next.js)는 계산된 좌표를 받아 그리기만 한다. 브라우저에서 Python 이
도는 것이 아니다. 실시간이 아니어도 되므로 **클라우드 GPU 없이 학교 PC 에서
돌릴 수 있고, 추가 요금이 들지 않는다.**

카메라가 고정이면 보정은 한 번만 하면 된다. 카메라가 흔들리거나 줌이 바뀌면
매번 다시 맞춰야 하므로, 삼각대 고정 촬영을 권한다.
